使い方

しくみ

スマホから正弦波を周波数を少しずつ変えながら鳴らし、マイクで受けた大きさを周波数ごとに測ります（ステップ正弦波法）。グラフの縦軸は入力の大きさ（dBFS：デジタルの最大値を0とした相対値）、横軸は周波数です。

スピーカー・イヤホンを測る

  • 静かな部屋で、測りたいスピーカー（またはイヤホン）とスマホのマイクを近づけて置き、「測定開始」。
  • スマホ自身のスピーカーとマイクで測ると、スマホのスピーカーの特性（低音はほぼ出ない）を測ることになります。

マイク・スピーカーの癖を差し引く（基準）

  • まず基準となる状態（例：回路を通さず直結、評判の良いスピーカー）で「基準として測定」。
  • 次に測りたいもので「測定開始」→ 表示を「基準との差」にすると、測定系の癖を差し引いた特性が見られます。
  • 基準はこのスマホに保存され、次回も使えます。

自作のアンプ・フィルタ回路を測る

  • スマホのヘッドホン出力 → 測りたい回路 → スマホのマイク入力とつなぎます（4極TRRSの分岐ケーブル、またはUSB-Cオーディオアダプタ）。
  • まず回路を通さず出力→入力を直結（減衰器経由）して「基準として測定」し、次に回路を入れて「測定開始」→「基準との差」で、回路だけの特性になります。
  • マイク入力は数十 mV程度で飽和します。抵抗分圧で20〜40 dB程度減衰させて入れてください。「1 kHzを鳴らす」で入力レベルを確認し、−6 dBFSより小さくなるよう調整します。
  • ヘッドホン出力やマイク入力にDCをかけないでください（必要ならコンデンサで切る）。

精度について

  • スマホのマイクは数十Hz以下と10 kHz以上で感度が下がります。基準測定で差し引くのが前提です。
  • 雑音の多い場所や、出力が小さすぎると、グラフがギザギザになります。出力レベルを上げるか静かな場所で。
  • 位相は測っていません（大きさのみ）。
